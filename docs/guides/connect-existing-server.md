Choose an existing server when you are connecting to something that is already running.

## Existing Server Types

- a LAN server discovered on your network
- a remote server entered manually by URL or IP
- an Eliza Cloud server

## What Happens Next

Once connected, the client should treat that server like any other:

- check whether onboarding is still required
- read the server’s current routing and capabilities
- open chat when the server is ready

The client should not assume the provider based only on the server type.
