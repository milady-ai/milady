Milady should start by asking **which server you want to use**, not which model provider you want.

## Your Options

- `Create one` for a new local server on this device
- a discovered LAN server for something already running on your network
- `Manually connect to one` for a known remote URL or IP
- `Use Eliza Cloud` when cloud credentials are available

## Important Rule

Choosing a server does **not** pick the model provider.

After the server is selected, that server can still be configured to use:

- local inference on its own machine
- OpenAI, Anthropic, OpenRouter, or other direct providers
- Eliza Cloud inference
