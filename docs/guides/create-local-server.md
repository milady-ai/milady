Choose `Create one` when the current device should run the Milady server.

That path should:

1. start or bootstrap the local runtime
2. continue into onboarding for that server
3. let you choose provider routing without forcing a cloud-only path

## What It Does Not Mean

Creating a local server does **not** require a local-only provider.

A local server can still use:

- Ollama or another local model
- OpenAI or Anthropic
- Eliza Cloud inference
