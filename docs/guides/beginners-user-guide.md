If you are new to Milady, use this order:

1. open the app
2. choose a server
3. finish onboarding for that server
4. pick a model provider
5. start chatting

Useful commands and actions:

- `milady start`
- `milady plugins install <name>`
- `milady plugins uninstall <name>`

If you want the browser-based consumer flow instead of the developer/reference docs, use the hosted guide hub at `milady.ai/guides`.
