The desktop app is the native shell around the Milady client and local runtime.

## Desktop Responsibilities

- show the startup chooser
- host the embedded local server when needed
- relay native capabilities to the renderer
- preserve a usable shell when the runtime hits startup problems

For local development, use [Desktop Local Development](/apps/desktop-local-development).
