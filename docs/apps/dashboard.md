---

The dashboard sits after startup and onboarding, not before them.

A user should reach the dashboard only after:

- choosing or restoring a server
- satisfying any pairing or auth requirements
- completing onboarding for that server when needed

That keeps the dashboard focused on the selected server instead of acting like the startup router.
