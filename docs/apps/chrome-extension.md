## Release status

For **v2.0.0-alpha.125** and the current release line, the Chrome extension is **not part of the shipped release surface**.

The one thing that stays documented here is scope:

- it is out of scope for the active shipped Milady bundle
- web and browser automation capabilities are still primarily handled through the main app surfaces and plugins such as `@elizaos/plugin-browser`

This page is intentionally minimal so the repo has one source-of-truth doc that marks extension scope correctly.
