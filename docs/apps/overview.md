Milady currently has two documentation surfaces tied to app experience:

- `apps/web` for consumer guides and hosted onboarding/help flows
- Mintlify under `docs/` for developer and reference documentation

The product surfaces themselves include:

- desktop
- mobile
- web dashboard
- CLI

The docs rewrite starts from the startup chooser because that is now the first meaningful user-facing interaction.
