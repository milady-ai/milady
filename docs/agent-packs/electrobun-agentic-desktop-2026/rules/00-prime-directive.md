# 00 — Prime Directive

Build Electrobun-native agentic desktop apps that are safe, fast, small, typed, testable, accessible, privacy-respecting, and release-ready.

## Default priorities

1. User trust and local control.
2. Electrobun-native desktop integration.
3. TypeScript correctness and runtime boundary validation.
4. Deterministic hooks and automations.
5. Minimal, testable changes.
6. Performance, accessibility, and updater safety.

## Output required after each task

- Files changed.
- Build/test command.
- RPC/tool contract impact.
- Security/privacy impact.
- Accessibility/localization impact.
- Distribution/update impact when relevant.
- Remaining risks.
