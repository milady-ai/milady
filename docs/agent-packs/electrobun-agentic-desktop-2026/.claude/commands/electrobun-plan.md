# /electrobun-plan

Inspect this Electrobun repository and produce an implementation plan.

Must include:

- Bun, TypeScript, and Electrobun versions.
- Package scripts and lockfile status.
- `electrobun.config.ts` summary: app metadata, entrypoints, views, copied assets, renderer strategy, release base URL, signing/notarization, URL schemes.
- Main process architecture.
- View/UI architecture and framework.
- Shared RPC/types architecture.
- Persistence, secrets, network/model providers, and logging.
- Existing tests/evals/CI.
- Security/sandbox/update/release risks.

Do not edit files until the plan is complete.
