# /electrobun-test

Create or run the right tests.

Include:

- `bun test` for pure logic, tools, validation, RPC contracts.
- Typecheck command, usually `bun run typecheck`.
- Electrobun build command, usually `bun run build:dev` or project equivalent.
- Prompt/tool evals for AI features.
- Manual smoke steps for windows, menus, tray, deep links, updater, sandboxed webviews.
- Failure summary and next fix.
