# /electrobun-view

Create or refactor an Electrobun window/view surface.

Include:

- `BrowserWindow`/`BrowserView` creation plan.
- `views://` bundled asset paths and config `copy` entries.
- UI framework integration preserving existing project conventions.
- Accessibility: semantic HTML, keyboard navigation, focus, labels, reduced motion.
- Localization/user-visible strings plan.
- RPC contract and loading/error/progress states.
- Sandbox/navigation rules if embedding external content.
- Renderer decision: system webview vs CEF.
