Milady has two supported entry paths:

- use the packaged desktop app from GitHub Releases
- install the CLI from the published `miladyai` npm package

## Desktop app

Use the latest packaged build from [GitHub Releases](https://github.com/milady-ai/milady/releases/latest).

That route is the best fit if you want:

- desktop tray and native OS integration
- chooser-first startup
- bundled local runtime support

## CLI

The published npm package name is `miladyai`.

```bash
npm install -g miladyai
milady
```

If you use Bun instead:

```bash
bun install -g miladyai
milady
```

## What happens first

The docs direction has changed from provider-first setup to server-first startup:

1. launch Milady
2. choose or discover a server
3. finish onboarding for that server if needed
4. choose the provider for chat
5. open chat

Use [Quickstart](/quickstart) for the current flow.
