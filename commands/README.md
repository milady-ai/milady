# Slash Commands

These command prompts are mirrored into `.claude/commands/` for Claude Code-style use. Other agents can paste them manually.

Recommended cadence:

1. `/electrobun-plan`
2. `/electrobun-port-apple` if translating Apple/Swift concepts
3. `/electrobun-rpc`, `/electrobun-agent-tool`, or `/electrobun-view` for implementation
4. `/electrobun-test`
5. `/electrobun-security-review`
6. `/electrobun-release`
