# /electrobun-port-apple

Port an Apple/Swift pattern to Electrobun only where a real equivalent exists.

Deliver:

- Source Apple concept and target Electrobun equivalent.
- Non-portable APIs explicitly excluded.
- Shared domain/service/RPC structure.
- UI surface mapping: view, command palette, menu/tray/context, deep link, updater flow.
- Persistence/secrets mapping.
- Test and release implications.
- Security/privacy differences.

Do not create fake Foundation Models, App Intents, SwiftUI, widgets, App Clips, StoreKit, or PassKit APIs.
